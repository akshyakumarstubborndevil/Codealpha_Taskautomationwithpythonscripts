# Codealpha_Taskautomationwithpythonscripts
Python automation script to move .jpg files from source folder to destination folder automatically using os and shutil modules.
This project is a simple Python automation script developed as part of my CodeAlpha Python Internship.
## Project Goal
Automatically move all `.jpg` files from a source folder to a destination folder.
## Technologies Used
- Python
- os module
- shutil module
## Features
- Detects `.jpg` files automatically
- Moves images from source folder to destination folder
- Simple and beginner-friendly automation project
## Folder Structure
task 3/
│
├── main.py
├── source/
└── destination/
## How to Run
1. Place `.jpg` images inside the `source` folder
2. Run the program:
   ```bash
   python main.py
